## 기기와 동기화

실제 Bluetooth API/권한/SDK는 호출하지 않는다. ‘모의 연결됨’은 Mock 상태만 뜻하며 모든 화면에 시뮬레이션을 고지한다. 초기 미연결·기록 없음, 연결 후에도 동기화 전에는 기록 없음이다. 연결 시도/권한 거절(가상)/시간 초과/연결 불가/중단/해제/재시도 상태를 구별한다.

동기화는 별도 동작이다. 정상·일시 오류·전송 실패·빈 목록·잘못된 데이터 시나리오를 제공한다. CI-01의 1/3/10초 최대 3회 재시도를 동기화 Mock에 적용한다(최초 요청+재시도 3회). 진행 중 중복 실행은 차단하고, 중단/해제 후 늦게 도착한 응답은 폐기한다. 실패·해제는 과거 기록과 마지막 정상 동기화 시각을 유지한다. 새 동기화 성공일 때만 최종 시각을 갱신한다.

기록은 deviceId+eventId로 중복 제거한다. 잘못된 지표가 포함된 응답은 전체 수신 묶음을 반영하지 않는다. 기록 ID는 데모 식별자만 쓴다. 실제 기기/사용자 식별정보와 연동하지 않는다.

## 양치 기록과 집계

- Mock 고정 예시 6건을 기준 시각에 상대적으로 생성하며 반복 동기화는 같은 이벤트를 반환한다. 실제 양치 수행/건강 개선 사실이 아니다. 점수·커버리지·시간은 각각 예시 제공값이며 서로 환산하거나 산식을 만들지 않는다.
- score/coverage는 유한한 0~100, duration은 0 이상 초, 누락은 null이다. null은 ‘미수신’으로 표시하고 0으로 변환하지 않는다. 영역 데이터는 명시적으로 제공된 6개 데모 구역만 표시하며 치아별/압력 센서 지원을 주장하지 않는다. Left 지표는 정의가 없어 제외한다.
- 기간은 오늘 포함 최근 7/14/30일, 기본 14일. 날짜 경계는 Asia/Seoul이다. 시간/커버리지 평균은 각 유효 수신값만 분모로 하며 수신 건수도 표시한다. 횟수/일은 기간 전체 일수로 나눈다. 데이터 없는 평균은 null, 기록 없음은 별도 빈 상태다.
- 추이는 날짜별 평균 커버리지이며 그날 수신값이 없으면 점/연결선을 그리지 않는다. 날짜/단위와 데모 표시, 접근 가능한 표를 함께 제공한다. 표시된 기록/필터는 상세 화면 복귀 시 유지한다.

## 영상 입력과 동의

시연용·비개인 영상만 선택하도록 고지한다. 영상 별도 동의 전 파일 선택/분석을 막고, 거절 상태도 안내한다. 파일은 해당 화면의 메모리에만 두고 화면 이탈·선택 해제·동의 철회 시 참조를 해제한다. 원본/파일명·영상 요약을 localStorage/IndexedDB/서버/로그에 보관하지 않는다. 카메라 촬영·업로드·실제 AI 판독은 구현하지 않는다.

파일 제한은 원본에 없으므로 [A]: MP4(.mp4, video/mp4) 또는 WebM(.webm, video/webm), 0바이트 초과~20MiB 이하, 알려진 형식 헤더 확인. MIME가 비어 있으면 확장자/헤더로 검사한다. 이는 형식/크기 검사이며 전체 파일의 디코딩 가능성·화질·길이·내용 검증은 아니다. 손상 헤더/미지원/빈 파일/초과를 분리 안내하고 선택 취소는 기존 선택을 바꾸지 않는다. 검사 후 원본 참조와 input 값을 즉시 해제하고 상태에는 형식·크기만 남긴다. 이후 모의 처리는 이 메타 상태만 사용하며 파일 내용은 사용하지 않는다.

입력 변경/해제/철회/이탈 시 진행 중 작업을 취소하고 이전 결과를 무효화한다. 처리는 정상·실패·저품질·저신뢰 Mock 상태로 재현한다. 저품질/저신뢰는 판정 유보·파일 교체/재촬영 안내, 실패는 재시도다. 정상 결과는 파일 내용에서 추론한 점수/영역을 생성하지 않고 ‘모의 처리 완료’와 개선 안내 예시만 표시한다. ‘본 정보는 진료·진단을 대체하지 않습니다’ 고지를 함께 제공한다.

## 영상과 세션 관계

독립 영상은 양치 기록을 만들지 않는다. 양치 상세에서 진입할 때 선택적 sessionId를 전달하며, 해당 세션이 존재하는 경우에만 연결 안내를 표시한다. 영상 결과로 기기 시간/점수/커버리지를 수정하지 않는다. 연결된 세션/영상 임시 상태는 메모리에만 있고 새로고침하면 초기화된다.

개발 모드는 `?demoDebug=1`에서만 오류 시나리오 선택을 노출한다. 일반 사용자에게는 연결/동기화·영상 체험 동작과 상태만 보여준다. Phase 4 상품/구독/개인정보 운영 삭제는 구현하지 않는다.
