## 승인 시점별 미결 사항

1. Phase 1 전: 화면/탭/라우트·토큰(D-003/014) 검토와 **Phase 1만** 명시 승인. 뒤 단계 데이터/거래 정책 승인으로 해석하지 않는다.
2. Phase 2 전: 설문·예시 평가/추천 규칙·비진단 조언(D-004/005/012). 자유 입력 등 민감정보 수집 범위 별도 확인.
3. Phase 3 전: 지표 의미·집계·영상 제한/동의·비영속 수명(D-006/007/011/018).
4. Phase 4 전: 상품/가격·구독 구성/주기·해지·판매 주소·삭제 범위/실패 정책(D-009~011).

현재 확정 경계는 사용자가 지시한 웹·Mock·원본 비영속이다. 추가 개인정보 수집·실거래·[F] 확장은 미승인으로 남긴다.
