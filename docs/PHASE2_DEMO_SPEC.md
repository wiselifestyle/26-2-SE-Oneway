# Phase 2 데모 설문 및 평가 규칙

2026-10-30. 사용자 Phase 2 승인에 따른 비임상 데모 명세 [A]. SSRD RQ-01~04/08, ONRQ-02와 SSAD BH-01~02/DCOM-01/03/06/OP-01에 대응한다. 원본의 미확정 내용을 실제 설문/의료 산식/제품 적합성으로 확정하지 않는다.

## 입력 경계

실제 개인정보·건강정보를 요청하지 않는다. 화면에 가상 인물의 응답만 선택하도록 고지하고 ‘가상 응답으로 체험’ 확인 후 문항을 활성화한다. 이름/연락처/자유 입력/파일/계정/서버 전송/브라우저 저장소는 없다. 동의하지 않으면 입력 불가, 홈 복귀 가능. 확인 해제 시 응답·결과·진행 요청을 무효화한다. 이 확인은 실제 서비스의 개인정보 동의 정책을 대체하지 않는다.

화면을 이동해도 같은 앱 메모리에서 진행 상태를 유지한다. 새로고침/탭 종료 시 초기화한다. 민감정보 수집 범위나 영속 저장을 확장하지 않는다.

## 설문 [A]

PDF p.12의 선택형 구성과 p.21의 4개 결과 항목만 참고했다. 아래 네 문항의 정확한 문구·선택지·필수 규칙은 원본 확정 설문이 아닌 데모 가정이다. 각 문항은 단일 선택 radio이며 모든 문항이 필수다.

| 키 / 문항 | 선택지 | 결과 표시 |
|---|---|---|
| sensitivity / 가상 인물의 시린 느낌은 어느 정도인가요? | 없음 / 가끔 / 자주 / 알 수 없음 | 시린이 |
| gums / 가상 인물의 잇몸 불편감은 어느 정도인가요? | 동일 | 잇몸 |
| teeth / 가상 인물의 치아 불편감은 어느 정도인가요? | 동일 | 치아 |
| breath / 가상 인물의 입냄새 고민은 어느 정도인가요? | 동일 | 입냄새 |

미선택과 ‘알 수 없음’은 다르다. 미선택은 제출 차단, 알 수 없음은 유효 응답이나 해당 결과는 null/평가 불가다. 해당 없음과 다른 선택이 동시에 존재할 수 없는 단일 선택 구조다. 추후 원본 전체 설문 제공 시 재검토한다.

## 결정적 응답 표시·조언

- 없음/가끔/자주를 표시 위치 0/50/100에 대응한다. 이는 **선택지의 시각 위치**이며 점수·백분위·질병 위험도·임계값이 아니다. UI에는 숫자 점수를 표시하지 않는다.
- 설명은 각 항목과 선택한 빈도를 명시한다. ‘없음’도 건강하다는 판정을 뜻하지 않는다. 알 수 없음/미수신은 바의 점을 표시하지 않는다.
- 조언은 모델 생성이 아닌 사전 정의 예시다. 항목·응답에 따라 달라지되 원인·질환·효능을 단정하지 않는다. ‘CAUSE’ 대신 ‘응답 분류 근거’를 표시한다.
- 결과·조언·추천에 ‘본 정보는 진료·진단을 대체하지 않습니다’ 고지를 표시한다. 상담 안내는 일반 안내이며 전문가 감수 완료를 주장하지 않는다. 일반 상담 문구 참고: [NHS 구강 증상 안내](https://www.nhs.uk/conditions/tooth-decay/), [NHS 잇몸 안내](https://www.nhs.uk/conditions/gum-disease/). 평가/추천 규칙의 근거로 사용하지 않는다.

## 추천 후보 4종 [A]

PDF p.21에 ‘교체용 팁 4종’ 개념은 있으나 팁별 명칭/사양/효능/호환이 없다. 따라서 A(시린이 응답 분류), B(잇몸), C(치아), D(입냄새)의 **데모 분류 후보**로만 구분한다. 실제 질환에 적합한 제품이라는 의미가 아니다.

평가 가능한 항목 중 ‘가끔/자주’에 해당하는 후보를 표시 위치 내림차순, 동률은 위 문항 순으로 정렬한다. 추천 이유는 ‘해당 가상 응답이 선택되어 후보를 분류했다’로 표시한다. 전부 없음/평가 불가면 맞춤 추천을 하지 않고 4종 개념의 일반 정보를 제공한다. 결과가 없거나 저신뢰/실패면 추천 보류다. 각 후보의 상품 정보는 Phase 4 준비 화면으로만 연결하며 가격·판매 URL·효능은 제공하지 않는다.

## 변경 및 오류 규칙

- 응답 변경마다 revision 증가, 기존 결과/조언/추천 즉시 무효화. 이전 ID 직접 진입도 결과 없음. 새 제출 후 동일 revision의 결과만 표시한다.
- 처리 중 중복 제출 차단. 입력/확인 변경·초기화 후 도착한 이전 요청 응답은 폐기한다. 실패/저신뢰 시 새 결과 생성 금지, 재시도 제공.
- 개발 전용 `?demoDebug=1`일 때만 실패/저신뢰/일부 결과 누락/조언 실패 시나리오 선택 UI 노출. 프로덕션에서는 개발 UI 없음. 재시도는 정상 시나리오로 실행할 수 있다.
- 영상·기기·상품/구독·설정 삭제 기능은 구현하지 않는다.
