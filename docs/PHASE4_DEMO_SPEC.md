## [A] 체험 정책

1. Catalog는 확인된 명칭/모델/URL만 보관한다. 외부 URL은 HTTPS + 정확한 oneway.or.kr 호스트만 허용한다. 새 탭/noopener/noreferrer, 링크 이동을 주문 확인으로 기록하지 않는다. 실접속 실패 감지는 브라우저 외부의 영역이므로 다시 열기/판매 홈 대안을 제공한다. 개발용 주소 없음·사용 불가 분기를 제공한다.
2. 구독은 상품 1개(그 판매 단위)·3/6개월 가상 주기, 체험 확인 필수. 주기는 판매 정책·교체 권장이 아니다. 주소/결제정보/계정 수집·외부 요청이 없다. 로컬 UUID는 주문 번호가 아니다.
3. 정상 adapter는 demo_requested, 확인 없음은 unconfirmed, 예외는 failed. 실제 주문/결제/배송 성공 상태는 없다. 중복 요청은 기존 intent 반환, 진행 중 추가 제출은 거부. 입력 변경/중단/삭제는 AbortController로 늦은 응답 폐기. 재시도는 자동 실주문을 생성하지 않는다. 가상 철회는 앱 안에서만 적용된다.
4. 체험 데이터는 현재 탭 메모리만 사용. 설문 철회는 응답·결과·확인을, 구독 철회는 구성·intent·확인을 지운다. 영상은 화면 이탈 시 consent/meta/result가 dispose되므로 설정 화면에서 영상 동의를 영구 보관한 것처럼 표시하지 않는다.
5. 삭제 확인 → 설문 reset / 양치 reset / 구독 reset. reset은 진행 작업과 과거 정상 데이터·동의·상태를 함께 무효화한다. 삭제 취소는 확인 체크만 해제하며 데이터는 보존한다. 결과는 성공 대상/실패 대상을 따로 표시하고 실패한 실제 상태를 보존한다. 개발용 양치 삭제 실패 → 재확인 후 정상 재시도. 다른 탭/외부 판매처/실서버 삭제·30일 보존·계정 탈퇴는 수행하지 않는다.
6. [디자인 보완] PDF에 구체 화면이 부족한 상품/구독/설정은 기존 흰색/파랑 토큰과 카드/폼/상태 안내를 따른다. 상품 실물 대신 Lucide Package 아이콘임을 밝히고, 검증되지 않은 이미지·사양·수치를 만들지 않는다. 추가 의존성 없음.
